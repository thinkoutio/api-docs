API-ul ThinkOut deschide datele unui spațiu de lucru către propriile tale instrumente. Folosește-l pentru a aduce încasările și plățile într-un instrument de BI sau pentru a le reconcilia cu un ERP.

Versiunea 1 acoperă citirea: fiecare endpoint este un `GET`, iar fiecare listă care poate crește se paginează la fel.

## URL de bază

```text
https://api.thinkout.io/v1
```

Toate cererile folosesc HTTPS. Răspunsurile sunt JSON cu chei în `snake_case`.

## Prima cerere

<Steps>
  <Step title="Creează o cheie API">
    În ThinkOut deschide **Setări** și creează o cheie pentru spațiul de lucru pe care vrei să îl citești. Cheia este afișată o singură dată. Vezi [Autentificare](/ro/guides/authentication).
  </Step>
  <Step title="Listează conturile">
    ```bash
    curl https://api.thinkout.io/v1/accounts \
      -H "Authorization: Bearer $THINKOUT_API_KEY"
    ```
  </Step>
  <Step title="Parcurge tranzacțiile">
    ```bash
    curl "https://api.thinkout.io/v1/transactions?from=2026-01-01&to=2026-03-31&limit=100" \
      -H "Authorization: Bearer $THINKOUT_API_KEY"
    ```
    Urmărește `next_cursor` până când `has_more` devine `false`. Vezi [Paginare](/ro/guides/pagination).
  </Step>
</Steps>

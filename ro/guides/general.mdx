title: "Start rapid"
description: "URL-ul de bază, o cheie și cele două apeluri cu care încep majoritatea integrărilor."
---

Fiecare apel merge la un singur URL de bază, prin HTTPS, și poartă o cheie
API. Primești înapoi JSON, cu chei în `snake_case`. Trei pași te duc de la zero
la prima pagină de tranzacții.

```text
https://api.thinkout.io/v1
```

## Prima cerere

<Steps>
  <Step title="Creează o cheie API">
    În ThinkOut, mergi la **Setări** → **Spațiu de lucru** și creează o cheie
    pentru spațiul pe care vrei să îl citești. Vezi
    [Autentificare](/ro/guides/authentication).
  </Step>
  <Step title="Listează conturile">
    ```bash
    curl https://api.thinkout.io/v1/accounts \
      -H "Authorization: Bearer $THINKOUT_API_KEY"
    ```

    Ar trebui să primești toate conturile din spațiul de lucru, fiecare cu
    soldul curent:

    ```json
    {
      "object": "list",
      "data": [
        {
          "object": "account",
          "id": "c2d7e8f9-1a2b-4c3d-8e9f-0a1b2c3d4e5f",
          "name": "ING Curent",
          "currency": "RON",
          "balance": "15230.45",
          "balance_as_of": "2026-09-03",
          "bank": "5d6e7f80-9a1b-4c2d-8e3f-4a5b6c7d8e9f"
        }
      ],
      "has_more": false,
      "next_cursor": null
    }
    ```
  </Step>
  <Step title="Parcurge tranzacțiile">
    ```bash
    curl "https://api.thinkout.io/v1/transactions?from=2026-01-01&to=2026-03-31&limit=100" \
      -H "Authorization: Bearer $THINKOUT_API_KEY"
    ```

    Urmărește `next_cursor` până când `has_more` devine `false`. Vezi
    [Paginare](/ro/guides/pagination).
  </Step>
</Steps>

<Note>
  O listă de tranzacții este un extras de cont: fiecare mișcare este un rând,
  inclusiv transferurile între conturile tale. Pentru cifre care se potrivesc
  cu aplicația, folosește endpoint-ul de
  [sinteză](/ro/api-reference/rapoarte/sintetizeaza-tranzactiile). Vezi
  [Modelul de date](/ro/guides/data-model).
</Note>

title: "Quickstart"
description: "The base URL, a key, and the two calls most integrations start with."
---

Every call goes to one base URL over HTTPS and carries an API key. You get
JSON back, with `snake_case` keys. Three steps take you from nothing to your
first page of transactions.

```text
https://api.thinkout.io/v1
```

## First request

<Steps>
  <Step title="Create an API key">
    In ThinkOut, go to **Settings** → **Workspace** and create a key for the
    workspace you want to read. See [Authentication](/guides/authentication).
  </Step>
  <Step title="List your accounts">
    ```bash
    curl https://api.thinkout.io/v1/accounts \
      -H "Authorization: Bearer $THINKOUT_API_KEY"
    ```

    You should get every account in the workspace, each with its current
    balance:

    ```json
    {
      "object": "list",
      "data": [
        {
          "object": "account",
          "id": "c2d7e8f9-1a2b-4c3d-8e9f-0a1b2c3d4e5f",
          "name": "ING Curent",
          "currency": "RON",
          "balance": "15230.45",
          "balance_as_of": "2026-09-03",
          "bank": "5d6e7f80-9a1b-4c2d-8e3f-4a5b6c7d8e9f"
        }
      ],
      "has_more": false,
      "next_cursor": null
    }
    ```
  </Step>
  <Step title="Page through transactions">
    ```bash
    curl "https://api.thinkout.io/v1/transactions?from=2026-01-01&to=2026-03-31&limit=100" \
      -H "Authorization: Bearer $THINKOUT_API_KEY"
    ```

    Follow `next_cursor` until `has_more` is `false`. See
    [Pagination](/guides/pagination).
  </Step>
</Steps>

<Note>
  A transaction list is a bank statement: every movement is a row, including
  transfers between your own accounts. For figures that match the app, use the
  [summary](/api-reference/reports/summarise-transactions) endpoint. See
  [Data model](/guides/data-model).
</Note>

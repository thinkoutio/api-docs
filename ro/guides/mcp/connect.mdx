Te autentifici cu contul tău ThinkOut, același pe care îl folosești în
aplicație, iar asistentul vede doar spațiile de lucru la care i-ai dat acces.
Clienții care nu se pot autentifica pot trimite în schimb o
[cheie MCP](#cheie-mcp).

## Claude

<Steps>
  <Step title="Deschide setările pentru conectori">
    În Claude, mergi la **Customize** → **Connectors**, apasă **+** și alege
    **Add custom connector**.
  </Step>
  <Step title="Adaugă serverul">
    Denumește-l `ThinkOut`, pune adresa `https://mcp.thinkout.io` și apasă
    **Add**. Lasă setările avansate goale.
  </Step>
  <Step title="Autentifică-te">
    Apasă **Connect** lângă ThinkOut și autorizează cu contul tău ThinkOut.
  </Step>
  <Step title="Activează-l în conversație">
    Într-o conversație, deschide meniul **+**, alege **Connectors** și verifică
    dacă **ThinkOut** este pornit.
  </Step>
</Steps>

<Note>
  Pe planurile Team și Enterprise, un owner adaugă conectorul din
  **Organization settings** → **Connectors** → **Add** → **Custom** → **Web**.
  Membrii îl găsesc apoi în **Customize** → **Connectors** și apasă
  **Connect**.
</Note>

## Claude Code

Deschide terminalul și scrie:

```bash
claude mcp add --transport http thinkout https://mcp.thinkout.io
```

Apoi rulează `/mcp` și finalizează autentificarea în browser.

## Codex

Deschide terminalul și scrie:

```bash
codex mcp add thinkout --url https://mcp.thinkout.io
codex mcp login thinkout
```

## Gemini CLI

Adaugă serverul în `~/.gemini/settings.json`:

```json
{
  "mcpServers": {
    "thinkout": {
      "httpUrl": "https://mcp.thinkout.io"
    }
  }
}
```

Apoi rulează `/mcp auth thinkout`.

<Note>
  Pe Gemini Enterprise, administratorul trebuie să ceară mai întâi credențiale
  de client de la echipa ThinkOut.
</Note>

## ChatGPT

<Steps>
  <Step title="Activează developer mode">
    În ChatGPT, în browser, mergi la **Settings** → **Security and login** și
    activează **Developer mode**.
  </Step>
  <Step title="Adaugă pluginul">
    Deschide **Plugins**, apasă **+**, denumește-l `ThinkOut`, adaugă o descriere
    scurtă, pune adresa `https://mcp.thinkout.io` și alege **OAuth** ca metodă de
    autentificare.
  </Step>
  <Step title="Autentifică-te">
    Creează-l, verifică instrumentele găsite de ChatGPT și autorizează cu contul
    tău ThinkOut.
  </Step>
  <Step title="Activează-l în conversație">
    Într-o conversație, deschide meniul **+**, alege **Developer mode** și
    bifează **ThinkOut**. Un plugin salvat rămâne oprit până îl activezi în
    conversație.
  </Step>
</Steps>

<Note>
  Developer mode necesită un plan plătit și funcționează doar în browser. Pe
  spațiile de lucru Business și Enterprise, un administrator trebuie să permită
  mai întâi conectorii MCP personalizați, din **Workspace Settings** →
  **Permissions & Roles** → **Connected Data**.
</Note>

## Alți clienți

Orice client compatibil MCP care suportă Streamable HTTP se poate conecta la
adresa `https://mcp.thinkout.io`, fie prin autentificare, fie trimițând o cheie
MCP ca bearer token.

## Cheie MCP

Unii clienți nu pot parcurge autentificarea interactivă. Aceștia se pot
autentifica direct: creează o cheie MCP în ThinkOut, din **Contul meu**, și
trimite-o în antetul `Authorization`.

```bash
claude mcp add --transport http thinkout https://mcp.thinkout.io \
  --header "Authorization: Bearer $THINKOUT_MCP_KEY"
```

Într-un client care are propriul fișier de configurare:

```json
{
  "mcpServers": {
    "thinkout": {
      "httpUrl": "https://mcp.thinkout.io",
      "headers": {
        "Authorization": "Bearer <cheia ta>"
      }
    }
  }
}
```

<Note>
  O cheie MCP aparține contului, nu unei persoane, așa că ajunge la toate
  spațiile de lucru din cont, nu doar la cele pe care le poți deschide tu.
  Funcționează până când o regenerezi sau o revoci. Acolo unde clientul
  permite, autentifică-te în locul ei.
</Note>
